CALLKEEPER 1.0 - RENAMED FROM MEETING DIRECTORY

UPGRADE INSTRUCTIONS
Back up your meetings and close Meeting Directory completely. Extract the CallKeeper release into a new folder and open CallKeeper.exe. Existing meetings and settings load automatically from the same data location. There is no need to import them. Both programs share the same instance lock; opening one while the other is running shows a message instead of opening a second editor.

The saved directory remains %LOCALAPPDATA%\MeetingDirectory so existing data is preserved. Keep using CallKeeper after upgrading.

CALLKEEPER 0.6 - MENU BAR UPDATE

UPDATING
1. In the current version, back up your directory before upgrading.
2. Close the old application completely.
3. Extract this download into a new folder.
4. Open CallKeeper.exe in that folder.
Your saved meetings and settings load automatically. No import or restore is needed. Use the new executable going forward. No PowerShell, VS Code or separate .NET installation is needed.

WHAT CHANGED
A standard Windows Forms menu bar now contains the helpful commands. The main window retains only Open meeting and Add meeting buttons, plus Search, View, Category, the meeting list and meeting details. Existing shortcuts remain available.

Press Alt or F10 to reach the menu bar, then use arrows and Enter.
Alt+F: File - Paste invitation, Import shared meetings, Export selected meetings, Back up, Restore backup, Exit.
Alt+M: Meeting - Add, Edit, Open, Mark or remove favorite, Manage exceptions, Delete.
Alt+V: View - Today, Upcoming, Favorites, All meetings, Search, Category filter, Refresh.
Alt+H: Help - User guide, Keyboard shortcuts, About.
Escape closes a menu. Keyboard shortcuts appear beside menu commands where applicable. View choices and favorite status have checkmarks. Commands that need a selected meeting are disabled when there is no selection.

VALIDATION
Compiled as a self-contained 64-bit Windows executable. All 61 automated schedule, storage and feature checks passed. This menu update has not been tested interactively with JAWS, NVDA or Narrator; please verify Alt navigation, command announcements and focus return after closing a menu. The earlier version passed the user's hands-on Windows and JAWS checks. The executable remains unsigned and Windows may display a publisher notice.

QUICK FIRST CHECK
Open the application, press Alt+F, and listen for the File menu. Arrow through the commands. Press Escape to close it. Your current meeting selection should remain available.

CALLKEEPER 0.6

MENU BAR
Press Alt or F10 for the menu bar. Alt+F opens File; Alt+M Meeting; Alt+V View; Alt+H Help. Use arrows to browse and Enter to activate. Escape closes a menu. File contains invitations, imports, exports, backup, restore and Exit. Meeting contains Add, Edit, Open, Favorite, Exceptions and Delete. View contains Today, Upcoming, Favorites, All, Search, Category and Refresh. Help contains the User guide, Keyboard shortcuts and About. Commands needing a selected meeting are disabled when none is selected. The current view and favorite state are checked in their menus.
Only Open meeting and Add meeting buttons remain on the main window. All other commands are available through the menus. Existing keyboard shortcuts continue to work.

QUICK KEYS
Ctrl+N adds a meeting. Ctrl+F searches. Ctrl+E edits the selected meeting. Ctrl+I opens Paste invitation. Ctrl+1 Today's meetings; Ctrl+2 Upcoming; Ctrl+3 Favorites; Ctrl+4 All meetings. Enter on the meeting list opens the selected link. F5 refreshes; F1 opens this help. Tab and Shift+Tab move between controls; arrows browse choices; Space checks days and monthly positions.

TODAY, UPCOMING AND FAVORITES
Today includes all starts on today's date in your computer's current local time zone, including calls that have already started. No end times or live attendance are tracked. Upcoming lists each meeting's next occurrence. Favorites lists your marked meetings even if they have no upcoming occurrence. Search and category filters apply to each view. Saving a meeting reveals it in All meetings. Meeting > Mark as favorite toggles the selected meeting; it is also available in the editor.

CATEGORIES
Choose or type one category in the meeting editor, such as Community, Work, Classes or Personal. The main window can filter by that category, All categories, or Uncategorized. Categories are optional; searching still matches name and notes.

PASTE INVITATION
Paste the full invitation and choose Analyze invitation. Choose a link if multiple links are found, then Review before saving. Supported direct Zoom and Teams links are recognized without visiting websites. Topic/subject, explicit dates in ISO or English month format, AM/PM time, common US time zones, ID, passcode and explicit daily recurrence may be suggested. Other recurrence patterns must be set manually. Missing fields have defaults: review name, date, time, time zone and recurrence before saving. The full original invitation is kept in Notes. Shortened links, protected email links, attachments and calendar files are not decoded. No invitation is saved until you press Save in the meeting editor.

OPTIONAL REMINDERS
In the meeting editor choose Off, At meeting time, 5, 10, 15 or 30 minutes before, 1 hour before, or 1 day before. Reminders work only while this application is open, including when minimized. They do not wake the computer and do not run after you exit. The app checks every 15 seconds. On startup or resume a missed advance reminder can appear if the meeting has not yet started. A reminder window and the Windows alert sound notify you; actual speech depends on your screen reader and Windows sound settings. Select a reminder and activate Open meeting, Dismiss highlighted, or Close all. A local alert log avoids repeating already delivered reminders across restarts. Imported shared meetings have reminders off until you enable them.

EXCEPTIONS
Select a meeting and choose Meeting > Manage exceptions. Enter the original scheduled date in the meeting's own time zone. Choose Skip this occurrence or Change this occurrence's date or time. For a change, choose the new date and time in the same time zone. Activate Add or update exception, then Save exceptions. Removing an exception restores the normal occurrence. This only changes the directory, never the host's actual meeting. A schedule edit that invalidates existing exceptions is rejected; first remove those exceptions if the series itself must change.

SHARING
File > Export selected meetings opens a checked list. Only checked meetings are exported. Notes and separate passcode fields are excluded unless you choose to include them, but links themselves can contain passcodes. Favorites and reminders are personal and excluded. No file is sent automatically. File > Import shared meetings lets you review and select entries; it adds new entries and skips duplicates without changing existing ones. Existing identifiers are considered duplicates; separately created entries with the same name, link and schedule are also skipped. A duplicate never overwrites your version. Use Edit for intentional changes. Imported reminders stay off and favorites stay unmarked.

BACKUP AND UPGRADE
Back up includes all meeting data. Restore replaces the directory after confirmation; Import shared meetings adds instead. Existing version 0.1 directories load automatically. Before the first 0.2 save, the prior data is retained as meetings.json.before-v02. After upgrading use the new executable: editing with the old application can discard fields it does not understand. Data files and backups include readable links and passcodes, so protect them. No cloud syncing, analytics, account system or automatic joining is included.

SCHEDULE RULES
Schedules use the stored meeting time zone and its daylight saving rules. A nonexistent spring-forward time is skipped for recurring meetings and rejected for a one-time meeting or moved occurrence. A repeated fall-back time uses its earlier occurrence once. Dates absent from a month are skipped. Exceptions can move occurrences into or out of Today and Upcoming. If two occurrences are moved to the same instant, Today shows both and reminders treat them separately.

SUPPORTED LINKS
Use complete direct HTTPS Zoom links under zoom.us, zoom.com or zoomgov.com, or Teams links at teams.microsoft.com, teams.live.com or teams.cloud.microsoft. Your configured meeting application or browser opens them. The meeting host may require sign-in. Meeting ID and passcode fields are reference information; they do not modify the link.


CALLKEEPER 0.6: IMPORTING YOUR ZOOM LINKS

Quick start
1. Open CallKeeper_Import_Template.xlsx in Excel.
2. On Guide, rename Account 1 through Account 7 to your account labels.
3. Switch to Meetings. Starting at row 2, enter MeetingName, the complete MeetingLink, and ZoomAccount. Use the same account spelling for related links. One meeting per row. The template has 100 blank rows and can be extended.
4. For reusable room links, leave Schedule and date/time fields blank. You can add schedules later in Edit Meeting. The links appear in All meetings, not Today or Upcoming.
5. Save the workbook as your master copy. With Meetings active, Save a Copy or Save As CSV UTF-8 (Comma delimited). Export only that sheet. Keep the headers unchanged.
6. In CallKeeper, make a backup using File > Back up. Then choose File > Import CSV. Select your CSV, review the checked meetings, and choose Import checked. Space changes a checkbox. Cancel saves nothing.
7. Press Ctrl+4 for All meetings. Tab to Filter by Zoom account and choose your account label. All Zoom accounts clears this filter.

Ctrl+S activates Save in both Add Meeting and Edit Meeting, including while you are writing Notes. Validation is the same as using the Save button. A validation message leaves your changes in the editor.

Account labels
ZoomAccount is an organizational label of up to 100 characters, such as the community or host account name. It is stored with the meeting and included in backups and shared exports. It does not sign in to Zoom or switch your active Zoom account. Zoom's own sign-in and meeting permissions still apply. Never put an account password in this file.

CSV fields
The minimum headers are MeetingName and MeetingLink. The template includes all supported columns. Header spelling can contain spaces and is not case-sensitive. Unknown or duplicate columns are rejected so a typo does not silently discard data.
MeetingName: required, 1 to 200 characters.
MeetingLink: required, full direct HTTPS Zoom or Teams link; preserve the entire query string.
ZoomAccount: recommended for Zoom; leave blank for Teams.
Platform: optional, Zoom or Teams. Blank detects it from the link.
MeetingID: optional text. Keep leading zeros.
Passcode: optional meeting passcode, stored as text; not an account password.
Category: optional group of up to 100 characters, such as Community.
Schedule: blank or Unscheduled saves a room link. Other choices are Once, Daily, Weekly, MonthlyDate and MonthlyWeekday.
StartDate: required for scheduled entries, yyyy-mm-dd, for example 2026-11-04.
StartTime: required for scheduled entries, 24-hour HH:mm such as 19:00, or h:mm AM/PM such as 7:00 PM.
TimeZone: required for scheduled entries. Eastern, Central, Mountain, Pacific and UTC are accepted, as are exact Windows/IANA time-zone identifiers. US regional names follow daylight saving rules where applicable; for Arizona or another region use its exact zone.
Weekdays: Weekly only; names separated by semicolons, for example Monday;Wednesday.
MonthDay: MonthlyDate only, 1 through 31. Months without that day are skipped.
MonthPositions: MonthlyWeekday only; First;Third, for example. Supports First, Second, Third, Fourth, Fifth and Last.
MonthWeekday: MonthlyWeekday only; one weekday name, for example Tuesday.
EndDate: optional last date for recurring meetings, yyyy-mm-dd.
Notes: optional text. Excel CSV UTF-8 exports quoted commas, quotes and line breaks correctly.

Leave date, time, weekday, monthly and end-date fields blank for unscheduled links. Supply only the recurrence fields relevant to your chosen schedule.

Review and error handling
Nothing is saved until you choose Import checked. If any CSV line is invalid, no meetings are imported; a readable, selectable error window lists the line numbers. Correct the spreadsheet, export CSV UTF-8 again, and retry. Blank rows are ignored. The import accepts up to 10,000 rows and a 20 MB file, and your combined directory cannot exceed 10,000 meetings.
Changed links can be reviewed before saving. Reimporting the same names, links, account labels and schedules skips duplicates. The same link in two different account labels remains separate. New names or changed account labels/schedules count as new meetings, so edit existing entries when you intend to change them. Imported reminders and favorites are off. Account labels are also available in Add/Edit Meeting and Search.

Your workbook and CSV may contain private meeting links and passcodes. Store and share them accordingly. Existing saved directories and backups still load; older entries have no Zoom account label until you add one.

VERSION 0.6 ORGANIZER COMMANDS

Copy links and invitations. Select a meeting, then choose Meeting > Copy link or Copy invitation. With focus on the meeting list, Ctrl+Shift+C copies the link. Press Enter to dismiss the clipboard confirmation. An invitation includes the name, link, scheduled time when available, and saved meeting ID and passcode when they apply. Paste the copied text into a message when ready.

Startup settings. Choose View > Startup settings. Select the view to open on the next launch. Check Remember the last Zoom account filter to restore the filter that was selected when you closed CallKeeper. If a remembered label no longer exists, the program opens with all account labels visible in the selected view. These preferences are stored on this computer separately from meeting backups.

Bulk labels. Choose Meeting > Change labels for multiple meetings. Use arrows to browse and Space to check meetings. Choose Continue, check the fields to change, and enter or pick the labels. A checked field left blank clears that label. Account changes apply to Zoom entries. Category changes can apply to both Zoom and Teams.

CSV link changes. Import a CSV and check the rows you want. A changed link with one matching saved entry and one matching checked row (same name, platform and account label) opens a review showing both links. Choose Update link, Keep current link, or Add as separate meeting. Update uses the CSV meeting ID and passcode, including blank fields, and keeps the saved schedule, notes, reminders and favorites. Ambiguous changed rows are listed in the import results and skipped. Cancel import discards all decisions made in that import.

One-time room changes. Select a scheduled meeting and choose Meeting > Manage exceptions. Pick the original scheduled date in the meeting's time zone. Choose Change link only, or Change date or time with an optional replacement link. Paste the direct link for the same meeting platform, choose Add or update exception, then Save exceptions. Open meeting, Copy Link, Copy Invitation, and reminders use that occurrence's replacement link. Today uses the selected occurrence and Upcoming, Favorites and All use the next occurrence when one exists. The regular series link applies on other dates.

CLEAR ALL FILTERS
Press Ctrl+Shift+F or choose View > Clear all filters to clear Search, Category and Zoom account and show All meetings. Focus moves to the meeting list. When CallKeeper opens, focus starts in Search. Tab moves through the view and filters, meeting list, meeting details, and Open and Add buttons.
